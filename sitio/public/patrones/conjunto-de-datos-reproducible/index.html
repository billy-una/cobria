Analítica reproducible · Patrón 14

Conjunto de datos reproducible

Poder regenerar un conjunto analítico con la misma selección, corte, vocabulario y transformación.

Problema que resuelve

Un archivo exportado sin contexto no explica qué registros faltan, qué versión utilizó ni cómo repetir un resultado.

Analogía

Es una receta con ingredientes, cantidades y fecha de cosecha, no solo una fotografía del plato.

Solución y contrato

El contrato registra fuentes, ámbitos autorizados, tiempo de corte, consulta, transformación, esquema, catálogo, resumen criptográfico y política de faltantes.

conjunto = construir(corte, fuentes, versiones, semilla)

Cuándo aplicarlo

Úselo para minería, entrenamiento, auditoría e informes. No publique datos personales por reproducibilidad; separe metadatos repetibles de contenido restringido.

Ejemplo ejecutable

Ejemplo pedagógico; no es una declaración de conformidad con Core 1.0. El manifiesto fija consulta, corte, catálogo, transformación y huellas.

Estudio anual de presencia de aves: El conjunto cambia cada vez que alguien corrige una observación histórica.

Desde la raíz del repositorio, Node.js 22.13 o superior. La instalación requiere acceso al registro de paquetes.

Instalar y comprobar

npm ci --prefix replication
npm test --prefix replication/examples/patterns-r4

Resultado esperado: casos conformes y adversos de los treinta patrones y regresiones PC1 aprobados. El comando indica el conteo vigente. Los fragmentos usan tipos y ayudantes del proyecto completo.

TypeScript

export function conjuntoReproducible(entrada: Entrada): Resultado {
  const fuentes = lista(entrada, "fuentes").map(String).sort();
  const corte = texto(entrada, "corte");
  const semilla = numero(entrada, "semilla");
  try { fechaIso(corte); } catch { throw new ErrorPatron('CUT_INVALID', 'El corte temporal no es válido'); }
  return { manifiesto: { fuentes, corte, semilla, transformacion: texto(entrada, "transformacion") }, autoridadEscritura: false };
}

Alternativa más sencilla

Exportación puntual documentada. Suficiente cuando no se promete repetición exacta.

Cuándo no usarlo

No adopte Conjunto de datos reproducible si el problema no fue observado o una alternativa más simple satisface el contrato.

Costo que debe medir

Mida cobertura de procedencia, diferencias entre reconstrucciones y registros en cuarentena. Se relaciona con Dato fechado y Característica versionada.

Límite de esta demostración

Ordenar referencias no congela sus contenidos ni calcula huellas.

Práctica guiada

Reconstruya el mismo corte dos veces y compare manifiesto, conteos y huellas.

  1. Prepare un caso válido.
  2. Provoque un fallo controlado.
  3. Conserve la evidencia.
