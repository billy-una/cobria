# Glosario canónico editorial de COBRIA

Este glosario gobierna el uso editorial general. Las definiciones normativas específicas
de Core prevalecen dentro de su versión correspondiente.

| Término canónico | Definición breve | Evitar o limitar |
|---|---|---|
| ámbito | límite organizacional, de seguridad o privacidad que restringe una operación | “tenant” sin traducción ni definición |
| autoridad de datos | representación autorizada para aceptar cambios de un hecho | “fuente única” cuando existen varias fuentes legítimas |
| catálogo | conjunto gobernado de valores o transformaciones identificados y versionados | lista mágica incrustada |
| conformidad | cumplimiento demostrable de una especificación y sus pruebas | certificación, salvo proceso externo real |
| contrato | reglas explícitas de entrada, salida, errores, compatibilidad y evolución | interfaz como simple firma técnica |
| dato canónico | dato cuya autoridad, identidad y reglas están declaradas | copia maestra como sinónimo universal |
| Dater | adaptador que traduce entre modelo de dominio y representación física de datos | repositorio, si además posee consultas y ciclo de vida |
| documento | unidad estructurada de un almacén documental NoSQL | fila o tabla cuando no corresponda |
| evidencia | artefacto que permite comprobar una afirmación bajo condiciones registradas | prueba como sinónimo de certeza universal |
| estado de madurez | condición explícita: propuesto, documentado, implementado, ejecutado, validado externamente o normativo | “listo” sin criterio observable |
| índice | estructura que acelera localización o consulta | proyección cuando no materializa una representación funcional distinta |
| manifiesto | declaración estructurada de fuentes, reglas, versiones, responsables y huellas | archivo de configuración sin procedencia |
| mecanismo | recurso técnico reutilizable que participa en una solución | patrón cuando no incluye contexto y consecuencias |
| nodo | unidad lógica o física de información con identidad, ciclo de vida y responsabilidad | colección como equivalencia automática |
| patrón | solución recurrente con contexto, problema, fuerzas, consecuencias y relaciones | receta obligatoria |
| procedencia | registro del origen y transformaciones relevantes de un dato o resultado | historial incompleto |
| proyección | representación derivada para una necesidad de lectura, integración o análisis | autoridad paralela |
| reconstrucción | regeneración de un derivado desde fuentes y reglas declaradas | restauración desde el derivado dañado |
| repositorio | frontera de acceso a agregados o documentos según reglas de dominio y ámbito | SDK de base de datos expuesto |
| revisión | orden lógico de cambios de una identidad | versión de esquema |
| versión | identificación de un contrato, transformación, catálogo o publicación | revisión de entidad |

## Nombres de productos

- Usar **COBRIA** para el ecosistema completo.
- Usar **COBRIA Core 1.0** para la norma congelada.
- Usar **COBRIA Ecosistema 1.0** para la primera edición pública integrada.
- Usar **COBRIA Pattern Design** para el catálogo central de patrones y antipatrones.
- Usar los nombres del mapa únicamente cuando se hable del módulo correspondiente.
- No usar “Atlas” como nombre de la arquitectura; puede describir el mapa navegable del
  sitio, pero el producto se denomina COBRIA.
