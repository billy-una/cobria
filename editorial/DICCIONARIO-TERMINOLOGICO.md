# Diccionario terminológico de COBRIA

Este vocabulario fija la forma preferida en español para el manuscrito, el
artículo condensado y los materiales de reproducción. Los identificadores de
código, nombres propios y títulos bibliográficos se conservan en su lengua
original cuando traducirlos impediría localizar la fuente o ejecutar el
programa.

| Forma preferida | Sentido en COBRIA | Formas que deben evitarse en la prosa |
|---|---|---|
| objeto canónico | representación mínima y estable del estado de una entidad | *canonical object* |
| dato fechado | observación con tiempo de validez y de registro | *dated data* |
| servicio de aplicación | coordinación de una operación del sistema | *service layer* |
| catálogo | vocabulario gobernado y versionado | lista maestra, *catalog* |
| ámbito organizacional | frontera explícita de aislamiento de datos | *scope*, *tenant* |
| proyección de lectura | representación derivada para una consulta concreta | *read model* |
| gestor de proyecciones | componente que construye, verifica y repara proyecciones | *projection manager* |
| almacén de características | sistema que publica variables reutilizables para IA | *feature store* |
| marca de avance temporal | límite conocido del procesamiento de eventos tardíos | *watermark* |
| conjunto de datos | colección analítica delimitada | *dataset* |
| prueba de rendimiento | medición controlada de tiempo y recursos | *benchmark* |
| remuestreo con reemplazo | procedimiento para estimar intervalos por simulación | *bootstrap* |
| ida y vuelta | recorrido completo de una solicitud | *round-trip* |
| en línea / fuera de línea | disponibilidad durante operación / procesamiento diferido | *online/offline* |
| registro de procedencia | evidencia de origen y transformaciones | *lineage* |
| deriva de datos | cambio estadístico relevante respecto de una referencia | *drift* |
| precisión / exhaustividad / F1 | métricas de clasificación o recuperación | *precision/recall* sin explicación |

## Regla editorial

La primera aparición de un término especializado incluye una definición breve.
Las siglas se introducen después del nombre completo. Los términos en inglés
solo aparecen en código literal, referencias bibliográficas o cuando son parte
del nombre oficial de una tecnología.
