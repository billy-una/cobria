# Consentimiento informado — borrador sujeto a revisión

**No usar para reclutar hasta recibir revisión ética apropiada.**

Se invita a evaluar si la documentación COBRIA permite comprender e implementar una tarea
de software. Se registrarán tiempos, resultados técnicos, dudas y respuestas voluntarias
sobre dificultad. No se solicitan datos laborales, credenciales, secretos ni código de un
empleador. La participación puede interrumpirse y sus datos pueden retirarse según el
procedimiento comunicado antes de comenzar. Los resultados se publicarán anonimizados.

Campos que debe completar una persona responsable: institución o responsable, contacto,
base de tratamiento, retención, riesgos, beneficios, compensación, retiro, aprobación y
versión del protocolo.
