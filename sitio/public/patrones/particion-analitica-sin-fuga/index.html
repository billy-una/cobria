Partición analítica sin fuga

Separar entrenamiento, validación y prueba sin contaminar tiempo, entidad ni ámbito.

Problema que resuelve

Una partición aleatoria puede colocar revisiones de la misma entidad a ambos lados y exagerar la calidad del modelo.

Analogía

Como estudiar aves por rutas distintas: no se cuenta la misma bandada como descubrimiento independiente.

Solución y contrato

Particione primero por entidad y tiempo, luego por ámbito; congele reglas y audite intersecciones antes de calcular métricas.

partirPor(entidad, tiempo, ámbito); exigir(intersección = ∅)

Cuándo aplicarlo

Úselo en minería de datos y aprendizaje automático. Documente exclusiones y conserve una prueba negativa de contaminación.

Ejemplo ejecutable

Ejemplo pedagógico; no es una declaración de conformidad con Core 1.0. La partición respeta grupos y tiempo antes de calcular características.

Predicción de floración: Observaciones futuras del mismo árbol aparecen en entrenamiento y validación.

Desde la raíz del repositorio, Node.js 22.13 o superior. La instalación requiere acceso al registro de paquetes.

Instalar y comprobar

npm ci --prefix replication
npm test --prefix replication/examples/patterns-r4

Resultado esperado: casos conformes y adversos de los treinta patrones y regresiones PC1 aprobados. El comando indica el conteo vigente. Los fragmentos usan tipos y ayudantes del proyecto completo.

TypeScript

export function particionSinFuga(entrada: Entrada): Resultado {
  const entrenamiento = lista(entrada, "entrenamiento") as Entrada[];
  const evaluacion = lista(entrada, "evaluacion") as Entrada[];
  const trainIds = new Set(entrenamiento.map((item) => texto(item, "entidadId")));
  exigir(evaluacion.every((item) => !trainIds.has(texto(item, "entidadId"))), "ANALYTICS_ENTITY_LEAKAGE", "Una entidad cruza particiones");
  return { entrenamiento: entrenamiento.length, evaluacion: evaluacion.length, fuga: false };
}

Alternativa más sencilla

Separación por entidad y tiempo. Aplicarla según la dependencia real de las observaciones.

Cuándo no usarlo

No adopte Partición analítica sin fuga si el problema no fue observado o una alternativa más simple satisface el contrato.

Costo que debe medir

Mida intersecciones, deriva temporal y rendimiento por ámbito. Se conecta con Conjunto reproducible y Característica versionada.

Límite de esta demostración

La prueba local detecta entidad compartida, no toda fuga temporal o semántica.

Práctica guiada

Particione un conjunto por entidad y tiempo; escriba una prueba que falle ante cualquier intersección.

  1. Prepare un caso válido.
  2. Provoque un fallo controlado.
  3. Conserve la evidencia.
