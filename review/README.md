# Paquete para revisión independiente

Este directorio prepara, pero no suplanta, una revisión humana independiente. El autor debe remitir la solicitud, la rúbrica, el manuscrito anonimizado y el directorio de replicación a una persona sin participación en el diseño ni en los experimentos.

Para preservar independencia:

1. use una persona intermediaria para retirar nombre y afiliación;
2. no comunique al revisor qué hipótesis desea apoyar;
3. conserve el informe original, fecha y código del revisor;
4. responda cada observación en una matriz de cambios;
5. declare relación previa o conflicto de interés.

Estado actual: **manuscrito ciego y solicitud preparados; revisión externa todavía no recibida**.

El PDF ciego se genera desde `blind-main.tex`. Antes de remitirlo, una persona
intermediaria debe comprobar metadatos, agradecimientos, rutas y cualquier referencia
indirecta que pueda revelar la identidad.
