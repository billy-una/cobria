Manifiesto de proyección

Explicar exactamente con qué fuentes y transformación se produjo un derivado.

Problema que resuelve

Una copia puede parecer correcta y aun mezclar semillas, versiones o cortes distintos.

Analogía

Como la ficha de una colección científica: origen, fecha, método y responsable acompañan al conjunto.

Solución y contrato

Guarde fuentes, cortes, versiones, parámetros, semilla, huellas y resultado de verificación como manifiesto inmutable.

manifiesto = sellar(fuentes, cortes, versiones, semilla, huellas)

Cuándo aplicarlo

Úselo en índices, conjuntos analíticos y publicaciones. El manifiesto referencia secretos sin copiarlos.

Ejemplo ejecutable

Ejemplo pedagógico; no es una declaración de conformidad con Core 1.0. La proyección publica receta, entradas, versión, huellas y responsable.

Mapa de corredores biológicos: Nadie recuerda con qué fuentes y filtros se produjo el mapa publicado.

Desde la raíz del repositorio, Node.js 22.13 o superior. La instalación requiere acceso al registro de paquetes.

Instalar y comprobar

npm ci --prefix replication
npm test --prefix replication/examples/patterns-r4

Resultado esperado: casos conformes y adversos de los treinta patrones y regresiones PC1 aprobados. El comando indica el conteo vigente. Los fragmentos usan tipos y ayudantes del proyecto completo.

TypeScript

export function manifiestoProyeccion(entrada: Entrada): Resultado {
  const fuentes = lista(entrada, "fuentes").map(String);
  const huellas = entrada.huellas as Record<string, string> | undefined;
  exigir(huellas && fuentes.every((fuente) => tiene(huellas, fuente) && /^[a-f0-9]{64}$/.test(huellas[fuente] ?? "")), "PROVENANCE_INCOMPLETE", "Cada fuente requiere una huella SHA-256");
  return { version: texto(entrada, "version"), fuentes, huellas, responsable: texto(entrada, "responsable") };
}

Alternativa más sencilla

Registro de exportación simple. Suficiente si no se promete reconstrucción verificable.

Cuándo no usarlo

No adopte Manifiesto de proyección si el problema no fue observado o una alternativa más simple satisface el contrato.

Costo que debe medir

Mida manifiestos incompletos, huellas inválidas y tiempo de reproducción. Se relaciona con Conjunto reproducible y Reparación verificable.

Límite de esta demostración

Validar formato de huella no comprueba el contenido al que apunta.

Práctica guiada

Reconstruya una proyección únicamente desde su manifiesto y registre cualquier dato implícito faltante.

  1. Prepare un caso válido.
  2. Provoque un fallo controlado.
  3. Conserve la evidencia.
