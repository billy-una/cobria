# Privacidad, minimización y retención

Antes de crear un atributo se registra propósito, clase (`público`, `interno`, `confidencial` o `restringido`), origen, consumidores, base organizacional, periodo y método de eliminación. Si no existe una finalidad verificable, el atributo no se recopila.

Los derivados no extienden automáticamente la retención del canónico. Borrar exige localizar canónico, proyecciones, índices, cachés, conjuntos analíticos, respaldos y evidencia permitida; luego se genera una constancia sin conservar el contenido borrado. La anonimización se considera una transformación verificable, no un cambio de etiqueta.

Para datos personales o sensibles se requiere revisión humana y jurídica aplicable al contexto. COBRIA aporta controles técnicos y trazabilidad; no certifica por sí mismo el cumplimiento de una ley.

La revisión periódica produce: inventario vigente, elementos vencidos, excepciones con responsable y fecha, evidencia de borrado y prueba de restauración que no reintroduzca datos expirados.
