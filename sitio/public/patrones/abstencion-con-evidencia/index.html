Abstención con evidencia

Responder solo cuando la evidencia autorizada sostiene la salida.

Problema que resuelve

Un sistema generativo puede completar vacíos con lenguaje plausible o citar fragmentos inexistentes.

Analogía

Como una guía responsable: si no observa señales suficientes, declara que no puede identificar la especie.

Solución y contrato

Defina umbrales, cobertura mínima, citas válidas y causas de abstención; la generación recibe únicamente evidencia autorizada.

si evidenciaInsuficiente entonces abstener(causaSegura)

Cuándo aplicarlo

Úselo en asistentes y automatizaciones. La abstención debe ser útil: explique qué falta sin revelar material prohibido.

Ejemplo ejecutable

Ejemplo pedagógico; no es una declaración de conformidad con Core 1.0. El asistente se abstiene, explica qué falta y conserva candidatos.

Asistente identifica una especie en una foto borrosa: El modelo podría inventar una respuesta segura sin evidencia suficiente.

Desde la raíz del repositorio, Node.js 22.13 o superior. La instalación requiere acceso al registro de paquetes.

Instalar y comprobar

npm ci --prefix replication
npm test --prefix replication/examples/patterns-r4

Resultado esperado: casos conformes y adversos de los treinta patrones y regresiones PC1 aprobados. El comando indica el conteo vigente. Los fragmentos usan tipos y ayudantes del proyecto completo.

TypeScript

export function abstencionConEvidencia(entrada: Entrada): Resultado {
  const confianza = numero(entrada, "confianza");
  const minimo = numero(entrada, "minimo");
  exigir(confianza >= 0 && confianza <= 1 && minimo >= 0 && minimo <= 1, 'CONFIDENCE_INVALID', 'Confianza y mínimo deben estar entre cero y uno');
  const candidatos = lista(entrada, "candidatos").map(String);
  return confianza < minimo
    ? { estado: "abstencion", causa: "EVIDENCIA_INSUFICIENTE", candidatos }
    : { estado: "respuesta", especie: candidatos[0], confianza };
}

Alternativa más sencilla

Respuesta manual o lista de evidencia. Preferirla si el umbral no puede calibrarse.

Cuándo no usarlo

No adopte Abstención con evidencia si el problema no fue observado o una alternativa más simple satisface el contrato.

Costo que debe medir

Mida precisión, cobertura, citas válidas, fugas y abstención apropiada. Se relaciona con Recuperación limitada por ámbito.

Límite de esta demostración

Una confianza recibida no demuestra calibración ni exactitud.

Práctica guiada

Retire evidencia suficiente y compruebe que la respuesta se abstiene con una explicación segura.

  1. Prepare un caso válido.
  2. Provoque un fallo controlado.
  3. Conserve la evidencia.
