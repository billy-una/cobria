# Casos desarrollados por área

Cada capítulo sigue el mismo proyecto de observaciones ambientales: problema,
vocabulario, explicación, ejemplo real o artefacto, alternativa, costo, caso adverso,
recuperación y ejercicio con solución. Empieza por el taller inicial si nunca has
programado. Los archivos se generan desde `editorial/ep3/chapters.mjs`; el libro y la
web leen la misma fuente.

Ejecuta los comandos desde la raíz de una copia completa de COBRIA, donde existe
`replication/`. La copia de solo `ecosistema-app` del taller inicial sigue sirviendo
para EP2; estos casos también reutilizan los talleres vecinos de operación y
analítica. No requieren paquetes nuevos, cuentas cloud ni credenciales.

No se exige un comando artificial para aprobar decisiones de diseño. Su rúbrica
requiere revisión de la entrega de una persona. Un ejemplo local no acredita
autenticación productiva, despliegue remoto ni comprensión por lectores.
