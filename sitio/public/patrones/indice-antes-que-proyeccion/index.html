Índice antes que proyección

Exigir una línea base nativa competente antes de añadir una representación derivada.

Problema que resuelve

Comparar solo contra escaneo exagera el beneficio y oculta una solución más sencilla del motor.

Analogía

Antes de construir una vía paralela, se mejora la señalización de la vía existente.

Solución y contrato

B0 diagnostica el costo bruto; B1 usa el mejor índice razonable; C1 debe compararse con ambos y pagar su mantenimiento. La equivalencia lógica de respuestas es obligatoria.

medir(consultaConÍndice) antesDe crearProyección()

Cuándo aplicarlo

Úsela en toda decisión de materialización. Excepciones requieren documentar por qué el motor no puede indexar la consulta.

Ejemplo ejecutable

Ejemplo pedagógico; no es una declaración de conformidad con Core 1.0. Se prueba primero una clave pequeña antes de mantener otra representación.

Búsqueda de viveros por cantón: El equipo quiere copiar fichas completas cuando un índice compuesto basta.

Desde la raíz del repositorio, Node.js 22.13 o superior. La instalación requiere acceso al registro de paquetes.

Instalar y comprobar

npm ci --prefix replication
npm test --prefix replication/examples/patterns-r4

Resultado esperado: casos conformes y adversos de los treinta patrones y regresiones PC1 aprobados. El comando indica el conteo vigente. Los fragmentos usan tipos y ayudantes del proyecto completo.

TypeScript

export function indiceAntesQueProyeccion(entrada: Entrada): Resultado {
  const ahorroIndice = numero(entrada, "ahorroIndice");
  const ahorroProyeccion = numero(entrada, "ahorroProyeccion");
  const costoProyeccion = numero(entrada, "costoProyeccion");
  exigir(ahorroIndice >= 0 && ahorroProyeccion >= 0 && costoProyeccion >= 0, "MEASUREMENTS_INVALID", "Las mediciones no pueden ser negativas");
  return { decision: ahorroIndice >= ahorroProyeccion - costoProyeccion ? "indice" : "proyeccion" };
}

Alternativa más sencilla

Medición del índice nativo. Compararla con consulta directa y proyección equivalente.

Cuándo no usarlo

No adopte Índice antes que proyección si el problema no fue observado o una alternativa más simple satisface el contrato.

Costo que debe medir

Mida plan, filas, bytes, p95 y escritura. En la fase confirmatoria, C1 solo superó significativamente a B1 en cuatro de nueve celdas.

Límite de esta demostración

Los números son entradas sintéticas, no resultados experimentales.

Práctica guiada

Añada primero un índice documental equivalente y mida antes de crear una copia.

  1. Prepare un caso válido.
  2. Provoque un fallo controlado.
  3. Conserve la evidencia.
