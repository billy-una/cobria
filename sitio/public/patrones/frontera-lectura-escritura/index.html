Frontera lectura—escritura

Decidir cuantitativamente si el ahorro de lectura compensa mantenimiento adicional.

Problema que resuelve

Las proyecciones suelen adoptarse por intuición y permanecen aun cuando un índice nativo sería suficiente.

Analogía

Una carretera nueva se justifica solo si el ahorro acumulado de viajes paga construcción y mantenimiento.

Solución y contrato

Si Δ Q=Q_{B1}-Q_{C1}>0 y Δ W=W_{C1}-W_{B1} , C1 compensa temporalmente cuando Q/W>Δ W/Δ Q . Se añaden almacenamiento, personal y riesgo cuando estén disponibles.

adoptar si ahorroLectura > costoEscritura + costoOperacional

Cuándo aplicarlo

Mida en el entorno objetivo y por percentil. Si Δ Q≤0 , B1 domina en esa métrica. No generalice el umbral entre motores, escalas o consultas.

Ejemplo ejecutable

Ejemplo pedagógico; no es una declaración de conformidad con Core 1.0. El resumen solo se lee; toda corrección entra por la medición canónica.

Resumen público de calidad del agua: Editar el resumen directamente lo convertiría en una segunda autoridad.

Desde la raíz del repositorio, Node.js 22.13 o superior. La instalación requiere acceso al registro de paquetes.

Instalar y comprobar

npm ci --prefix replication
npm test --prefix replication/examples/patterns-r4

Resultado esperado: casos conformes y adversos de los treinta patrones y regresiones PC1 aprobados. El comando indica el conteo vigente. Los fragmentos usan tipos y ayudantes del proyecto completo.

TypeScript

export function fronteraLecturaEscritura(entrada: Entrada): Resultado {
  exigir(entrada.operacion === "leer", "DERIVED_WRITE_FORBIDDEN", "Un resumen derivado no acepta escrituras");
  return { resumen: entrada.resumen, autoridadEscritura: false };
}

Alternativa más sencilla

Caso de uso único con comandos explícitos. Suficiente si conserva autoridad y rechaza escrituras derivadas.

Cuándo no usarlo

No adopte Frontera lectura—escritura si el problema no fue observado o una alternativa más simple satisface el contrato.

Costo que debe medir

El piloto observó umbrales entre 1.49 y 38.87 lecturas por escritura; son evidencia del método, no parámetros transferibles a NoSQL. Se relaciona con Proyección de cobertura y Retiro de proyección.

Límite de esta demostración

La función no aplica permisos del motor.

Práctica guiada

Calcule el punto de equilibrio con costos medidos y repita con el doble de escrituras.

  1. Prepare un caso válido.
  2. Provoque un fallo controlado.
  3. Conserve la evidencia.
