# Aceptación de un artefacto generado

- [ ] El nombre pertenece al lenguaje del dominio.
- [ ] El responsable reemplazó `POR-DEFINIR`.
- [ ] El contrato declara entrada, salida, errores, ámbito y evidencia.
- [ ] La prueba positiva demuestra el resultado observable.
- [ ] La prueba negativa demuestra una frontera real.
- [ ] Las dependencias siguen las capas permitidas.
- [ ] El manifiesto enlaza los cuatro artefactos.
- [ ] Una segunda generación devuelve `unchanged`.
- [ ] Ningún archivo preexistente fue sobrescrito.
