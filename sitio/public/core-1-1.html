COBRIA Core 1.1

Mayor precisión conceptual, trazabilidad normativa, seguridad explícita e implementación independiente del proveedor.

Definición

COBRIA es una propuesta arquitectónica para sistemas documentales NoSQL reconstruibles. No es una estructura de datos, un motor, un ORM ni un algoritmo de consenso.

Cinco capas

  1. Núcleo normativo.
  2. Catálogo de patrones.
  3. Mecanismos de implementación.
  4. Método de adopción.
  5. Implementaciones de referencia.

Requisitos trazables

Quince requisitos cubren autoridad, identidad, ámbito, revisiones, versión, procedencia, idempotencia, reconstrucción, equivalencia, publicación, observabilidad, retiro, analítica, IA y seguridad.

Adaptadores y evidencia

PouchDB y LokiJS poseen pruebas funcionales locales. MongoDB, CouchDB y OpenSearch conservan 270 corridas distribuidas históricas; deben repetirse con el oráculo corregido antes de tratarlas como evidencia confirmatoria actual. El sitio diferencia código preparado, evidencia histórica y validación vigente.

Estadística

La regeneración informa p50, p95, p99, intervalos bootstrap del 95 % y un cociente pareado, sin eliminar atípicos.

Evaluaciones complementarias

Se ejecutaron 540 controles comparativos, 300 inyecciones reales de fallos y 30 carreras locales que detectaron y repararon una candidata obsoleta. Dos adaptadores mutantes comprobaron que el arnés puede rechazar incumplimientos.

Estado científico

Core 1.1 continúa como borrador hasta repetir la infraestructura distribuida con el oráculo corregido y recibir revisión independiente.
