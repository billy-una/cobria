# Lista de preparación para publicación

- [x] Fuente, pruebas y resultados locales separan estados de evidencia.
- [x] Artículo ciego construible.
- [x] Paquete de transferencia con manifiesto SHA-256.
- [x] Protocolos de revisión, réplica y transferencia.
- [ ] Dos informes humanos independientes recibidos.
- [ ] Doble cribado bibliográfico completado.
- [ ] Estudio humano aprobado y ejecutado.
- [ ] Réplica externa recibida.
- [ ] Licencia pública elegida y revisada por el autor.
- [ ] Release firmado por una identidad autorizada.
- [ ] Depósito público y DOI verificados.

Los elementos pendientes impiden describir la fase como validación externa completada.
