# ADR-0010 — Contratos y accesibilidad por defecto

**Estado:** aceptada. **Fecha:** 2026-09-19.

## Decisión

La API neutral usa OpenAPI 3.1, problemas RFC 9457, cursor opaco, idempotencia y compatibilidad explícita. La interfaz apunta a WCAG 2.2 AA, conserva navegación en móvil y exige foco visible, enlace de salto, semántica y estados no dependientes del color.

## Consecuencias

Entradas, errores y evolución son comprobables. La automatización reduce regresiones, pero no sustituye pruebas manuales ni evaluación con personas usuarias.
