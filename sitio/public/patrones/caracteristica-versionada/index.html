Característica versionada

Definir una variable de modelo como transformación gobernada, no como columna accidental.

Problema que resuelve

Entrenamiento e inferencia calculan valores similares con código, ventanas o catálogos diferentes.

Analogía

Es una unidad de medida calibrada: el número carece de sentido sin definición y versión.

Solución y contrato

La ficha declara entidad, fórmula, ventana, fuente, versión, valores ausentes, frescura y equivalencia fuera de línea—en línea.

característica = calcular(definición, tiempoEvento, versión)

Cuándo aplicarlo

Úsela cuando una variable se comparte o influye en decisiones. Evite crear un almacén complejo para experimentos desechables sin ruta de producción.

Ejemplo ejecutable

Ejemplo pedagógico; no es una declaración de conformidad con Core 1.0. El valor viaja con la versión exacta de la fórmula que lo produjo.

Índice de sequedad para riesgo de incendio: Cambiar la fórmula altera predicciones sin explicar por qué.

Desde la raíz del repositorio, Node.js 22.13 o superior. La instalación requiere acceso al registro de paquetes.

Instalar y comprobar

npm ci --prefix replication
npm test --prefix replication/examples/patterns-r4

Resultado esperado: casos conformes y adversos de los treinta patrones y regresiones PC1 aprobados. El comando indica el conteo vigente. Los fragmentos usan tipos y ayudantes del proyecto completo.

TypeScript

export function caracteristicaVersionada(entrada: Entrada): Resultado {
  const humedad = numero(entrada, "humedad");
  const lluvia7d = numero(entrada, "lluvia7d");
  const formula = texto(entrada, "formula");
  exigir(formula === "is-2", "FEATURE_VERSION_UNKNOWN", "La fórmula no está registrada");
  return { valor: Math.max(0, 100 - humedad - lluvia7d * 2), formula };
}

Entrada conforme y resultado esperado

{
  "entrada": {
    "humedad": 31,
    "lluvia7d": 4,
    "formula": "is-2"
  },
  "esperado": {
    "valor": 61,
    "formula": "is-2"
  }
}

Entrada adversa y rechazo o abstención esperados

{
  "entrada": {
    "humedad": 31,
    "lluvia7d": 4,
    "formula": "is-3"
  },
  "codigoError": "FEATURE_VERSION_UNKNOWN"
}

Alternativa más sencilla

Variable cruda sin transformación. Preferirla si no existe una fórmula que mantener.

Cuándo no usarlo

No adopte Característica versionada si el problema no fue observado o una alternativa más simple satisface el contrato.

Costo que debe medir

Mida divergencia, frescura, uso y deriva. Se relaciona con Conjunto reproducible y Registro de dependencias.

Límite de esta demostración

Una fórmula de ejemplo no valida un modelo predictivo.

Práctica guiada

Cambie una definición de variable y confirme que produce una versión nueva.

  1. Prepare un caso válido.
  2. Provoque un fallo controlado.
  3. Conserve la evidencia.
