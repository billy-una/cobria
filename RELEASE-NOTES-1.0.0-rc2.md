# COBRIA Ecosistema 1.0.0-rc2

**Estado:** candidata pública no estable, propuesta independiente y no certificada.  
**Fecha de la candidata:** 23 de septiembre de 2026.  
**Repositorio canónico:** <https://github.com/billy-una/cobria>

## Alcance

Esta candidata integra la especificación normativa del ecosistema, el artículo
científico, el documento maestro, el libro pedagógico, el cuaderno de trabajo, el
anexo técnico, el sitio interactivo, el Toolkit y la evidencia reproducible. COBRIA
Core 1.0 permanece congelado y conserva su huella SHA-256 publicada.

## Cambios desde RC1

- separación explícita entre norma, implementación, evidencia y enseñanza;
- licencia y procedencia diferenciadas para código, contenido, datos e imágenes;
- ejemplos ejecutables y catálogo pedagógico de treinta patrones;
- evidencia confirmatoria interna R7 con 270 observaciones en tres motores;
- sincronización R8 de cifras, límites y resultados entre los productos editoriales;
- puerta R9 de construcción doble desde clones limpios, SBOM, manifiestos y huellas;
- sitio unificado, accesible y sin dependencias SQL activas.

## Límites

RC2 no constituye un estándar oficial, certificación, garantía de rendimiento ni
validación universal. La revisión humana independiente, el estudio con participantes,
la réplica externa y la decisión de publicación permanecen como actividades humanas o
externas. Los resultados locales no demuestran comportamiento distribuido.

## Artefactos esperados

El paquete contiene seis PDF, el sitio estático, las fuentes exactas, un SBOM
CycloneDX, licencias, guía de reproducción, incidencias conocidas, manifiesto JSON y
`SHA256SUMS`. La publicación solo debe realizarse si la auditoría pública confirma que
los archivos descargables coinciden con esas huellas.
