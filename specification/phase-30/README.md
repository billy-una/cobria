# Fase 30 — adjudicación dimensional trazable

La Fase 30 prepara la resolución de desacuerdos producidos por dos revisores auténticos en
la Fase 29. COBRIA continúa siendo una propuesta independiente: adjudicar no certifica el
proyecto, no convierte acuerdo en verdad y no autoriza alterar respuestas originales.

## Reglas

- La adjudicación solo comienza después de 72 juicios pareados válidos.
- Participa una tercera persona distinta de los dos revisores originales.
- Se revisan únicamente desacuerdos; los acuerdos no se reescriben.
- Cada elemento conserva ambas decisiones originales, resolución y justificación.
- Un conflicto de interés detiene la inclusión del resultado.
- Fixtures sintéticos prueban el mecanismo y no cuentan como revisión humana.
