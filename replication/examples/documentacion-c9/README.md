# Recorrido de documentación y Toolkit

Responsable: Billy Jak Cordero Porras. Versión 0.1.0, demostración local.
Desde la raíz: `npm ci --prefix replication`, después
`node replication/examples/documentacion-c9/recorrido.mjs`.

La [guía práctica](../../../manuales/34-documentacion-y-herramientas-practicas.md)
explica requisitos, resultados y límites. El recorrido crea una carpeta temporal
propia y conserva sus artefactos, sin publicar ni desplegar. Comprueba sintaxis y
contratos básicos, no la semántica de una aplicación terminada.
