# Archivo histórico de COBRIA

Esta carpeta conserva cortes reemplazados para trazabilidad. Ningún archivo contenido
aquí es una descarga canónica, una publicación estable ni una fuente de edición.

- `artefactos/pdf/`: libros, artículos y documentos maestros antiguos.
- `artefactos/paquetes/`: paquetes de revisión y réplica reemplazados.
- `artefactos/revision-core10/`: copia entregada en una revisión histórica.

Las fuentes vigentes y sus derivados se declaran en
`ARCHIVO-Y-FUENTES-CANONICAS.md`. Los tamaños y SHA-256 históricos se verifican mediante
`editorial/provenance.json`. Conservar un archivo no rehabilita afirmaciones superadas.
