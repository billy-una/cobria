# Agentes en la especificación

Esta carpeta contiene autoridad normativa. Distinga **DEBE**, **DEBERÍA** y **PUEDE**.
Todo requisito nuevo necesita ID, responsable, aceptación, prueba y trazabilidad. No cambie
COBRIA Core 1.0 congelado sin una nueva versión y ADR. Los manifiestos de `phase-11/` son
derivados: cambie la fuente y ejecute `make generar-manifiestos`.
