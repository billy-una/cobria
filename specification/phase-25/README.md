# Fase 25 — calibración dimensional de evidencia

Esta fase trata la revisión previa como simulación metodológica de una propuesta. No afirma
validación oficial ni certificación externa. Su hallazgo útil fue que una palabra como
`legacy` no basta para respaldar ENG-007.

El nuevo evaluador exige tres dimensiones independientes: frontera explícita, control
verificable contra crecimiento y condición o ruta de retiro. Lee únicamente objetos Git,
conserva huellas y clasifica `supported-structural` solo cuando las tres aparecen.

```bash
make verificar-fase-25
```

El resultado continúa siendo estructural y experimental. No sustituye ejecución del
proyecto, evaluación de calidad ni aprobación por una autoridad.
