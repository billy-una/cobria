Caso guiado de principio a fin

Cuando desaparece el índice del bosque

Una colección de observaciones conserva la autoridad; una proyección acelera búsqueda y puede reconstruirse sin inventar información.

1. Documento canónico

{ "id":"observacion-0042", "scope":"bosque-sur", "revision":3, "schemaVersion":2, "species":"colibri-garganta-fuego" }

Identidad estable, ámbito obligatorio y revisión monotónica.

2. Contrato

K = <observaciones, indexarTexto@2, catálogo@7, bosque-sur, búsqueda@4, 5min, mismaCobertura, reconstruirTotal, equipoDatos>

3. Fallo

La proyección activa se elimina. El expediente canónico y el catálogo permanecen.

4. Reconstrucción

  1. Congelar corte y versiones.
  2. Construir candidata separada.
  3. Transformar documentos autorizados.
  4. Comprobar identidades, revisiones y consultas.
  5. Publicar mediante alias.

5. Resultado

La consulta recupera la misma información, rechaza revisiones antiguas y devuelve cero documentos para otros ámbitos.

Prueba del lector

Interrumpa la candidata al 50 %, repita el lote y demuestre que la versión activa nunca queda vacía.
