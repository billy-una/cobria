# Rutas de aprendizaje COBRIA

## Estoy comenzando

Fundamentos → Layers → Build en memoria → Data → Pattern Design.

**Salida:** caso de uso pequeño, repositorio en memoria, interfaz simple y pruebas.

## Ya programo y quiero ordenar una aplicación

Inventario → Layers → Pattern Design → Quality → Security → migración Build.

**Salida:** un flujo vertical separado y una regla automatizada de dependencias.

## Diseño sistemas y datos

Data → Core → Performance → Cloud & Operations → Evidence.

**Salida:** decisión con contrato, alternativa, prueba y retiro.

## Construyo analítica o IA

Data → Security → Analytics & AI → Quality → Evidence.

**Salida:** resultado trazable que puede abstenerse y no adquiere autoridad.

## Soy un agente de IA

1. Leer `AGENTS.md` y la política más cercana.
2. Consultar Manifesto, identidad, mapa y especificación pertinente.
3. Declarar objetivo, alcance, autoridad, archivos, invariantes, pruebas y riesgos.
4. Trabajar sobre fuentes, no derivados.
5. Ejecutar el gate mínimo y el gate del producto.
6. Separar lo generado de la decisión humana.

**Salida:** cambio explicable, acotado, probado y sin afirmaciones inventadas.
