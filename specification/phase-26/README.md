# Fase 26 — rúbrica dimensional de COBRIA Engineering

La calibración de ENG-007 se generaliza a los ocho contratos. Cada uno posee tres
dimensiones obligatorias, un criterio observable y un ejemplo de evidencia insuficiente.
La plantilla resultante contiene 24 decisiones vacías: no convierte ausencia de evaluación
en incumplimiento y no produce puntuaciones oficiales.

## Reglas

- Las tres dimensiones son conjuntivas; no se compensan mediante promedio.
- `supported` exige evidencia para cada dimensión.
- `insufficient` describe falta de evidencia, no mala calidad del proyecto.
- La rúbrica no certifica seguridad, producción, personas ni cumplimiento normativo.

```bash
make verificar-fase-26
```
