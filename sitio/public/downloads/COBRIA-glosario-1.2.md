# Glosario operativo COBRIA

| Término | Significado | No debe confundirse con |
|---|---|---|
| Autoridad canónica | Representación autorizada para cambiar hechos y reglas | La copia más consultada |
| Ámbito | Límite obligatorio de identidad, autorización y partición | Un filtro opcional al final |
| Contrato | Condiciones de entrada, resultado, fallo y evidencia | Una interfaz sin semántica |
| Derivado | Representación obtenida de fuentes declaradas | Otra fuente independiente |
| Equivalencia | Regla congelada que compara significado relevante | Igualdad física de todos los campos |
| Manifiesto | Registro reproducible de fuentes, versiones y transformación | Un comentario informal |
| Mecanismo | Forma concreta de ejecutar una responsabilidad | La decisión de adoptarlo |
| Patrón | Solución recurrente con contexto y consecuencias | Requisito obligatorio por sí mismo |
| Proyección | Derivado orientado a una necesidad de lectura o análisis | Copia editable libremente |
| Reconstrucción | Regeneración desde autoridad y entradas declaradas | Restauración desde el derivado dañado |
| Revisión | Orden lógico monotónico de una entidad | Fecha de actualización solamente |
| Versión | Identidad del contrato, esquema o transformación | Revisión de un documento concreto |
