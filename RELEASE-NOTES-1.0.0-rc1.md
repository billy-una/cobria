# COBRIA Ecosistema 1.0.0-rc1

Esta es una **candidata reproducible de una propuesta independiente**, no una versión
estable, certificación ni estándar oficial.

## Contenido

- especificación del Ecosistema COBRIA 1.0 y Core 1.0 congelado;
- artículo científico y documento maestro;
- libro pedagógico, cuaderno de trabajo y anexo técnico;
- catálogo de treinta patrones y manuales del ecosistema;
- sitio interactivo, aplicación neutral, Toolkit y pruebas de conformidad;
- resultados, protocolos, amenazas a la validez y trazabilidad disponibles;
- licencias diferenciadas para código, textos, datos y recursos de terceros.

## Cambios editoriales relevantes

El libro, el cuaderno y el anexo técnico son productos separados. El sitio publica una
única descarga canónica por producto y conserva los materiales históricos fuera de esa
selección. Las afirmaciones distinguen ejecución local, evidencia histórica y validación
externa pendiente.

## Límites conocidos

- no existe todavía una repetición externa completa de la candidata;
- la lectura editorial, técnica y de claridad por personas independientes está pendiente;
- el estudio de transferencia con participantes requiere consentimiento y ejecución real;
- los PDF no se presentan como documentos accesibles certificados;
- el rendimiento observado no demuestra superioridad arquitectónica universal.

La candidata puede utilizarse para revisar, reproducir y reportar incidencias. No debe
renombrarse como versión estable hasta cerrar la fase 17 y obtener la autoridad humana
definida para la fase 18.
