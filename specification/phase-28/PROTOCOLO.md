# Protocolo dimensional

El coordinador entrega el mismo material a dos personas. Cada una completa 72 decisiones
sin comunicación entre ellas. Después del cierre se validan los archivos, se calcula
acuerdo por dimensión y se conservan todos los desacuerdos. Una eventual adjudicación debe
ser posterior, separada y trazable; nunca se altera una respuesta original.

No se calculará acuerdo mientras falte una decisión, una justificación o una atestación.
El porcentaje de acuerdo y kappa describen consistencia entre revisores, no verdad ni
calidad de los proyectos.
