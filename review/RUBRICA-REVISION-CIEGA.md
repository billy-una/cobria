# Rúbrica de revisión ciega

Use una escala de 1 (deficiente) a 5 (excelente) y justifique cada nota.

| Criterio | Pregunta de control |
|---|---|
| Relevancia | ¿El problema está motivado y delimitado? |
| Estado del arte | ¿Distingue con precisión patrones conocidos y aporte propio? |
| Novedad | ¿La contribución composicional/evaluativa es defendible? |
| Método | ¿Hipótesis, unidades, líneas base y exclusiones están predefinidas? |
| Implementación | ¿El artefacto neutral representa los constructos declarados? |
| Estadística | ¿Repeticiones, intervalos y tamaños de efecto sustentan las inferencias? |
| Validez | ¿Se discuten explicaciones alternativas y límites de generalización? |
| IA y minería | ¿Linaje, autorización y evaluación evitan afirmaciones exageradas? |
| Reproducibilidad | ¿Otra persona puede regenerar resultados y detectar desviaciones? |
| Escritura | ¿El texto es neutral, claro y coherente? |
