# Historial de COBRIA Core

## 1.0 — 2026-08-24

- Primera especificación normativa congelada.
- Define contrato nuclear, diez invariantes, ciclo de vida y niveles C1–C3.
- Fija P1, P2, R1, S1 y A1 como pruebas obligatorias.
- Limita la evidencia confirmatoria a motores NoSQL documentales.

## 1.1 — borrador, 2026-09-01

- Añade requisitos trazables AUT–SEC y perfiles C1–C3.
- Incorpora procedencia analítica, abstención y controles explícitos de ámbito.
- Permanece como borrador hasta recibir repetición y revisión externas.

## 1.2 — paquete experimental, 2026-09-01

- Corrige los oráculos R1, S1 y A1 para observar transformaciones, datos extranjeros, reconstrucción y rechazo de candidatas inválidas.
- Añade pruebas mutantes que demuestran que el arnés puede rechazar adaptadores defectuosos.
- Sustituye el banco de fallos tautológico por 300 inyecciones ejecutables.
- Demuestra localmente la obsolescencia de candidatas bajo concurrencia y su reparación por revisión.
- Añade modelo formal mínimo, matriz integral de trazabilidad y el comando `cobria verificar`.
- No promueve Core 1.1 ni Core 1.2 a norma estable; Core 1.0 continúa congelado.
